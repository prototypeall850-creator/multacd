# Quickstart (5 menit)

```bash
multacd
```

Pertama kali: setup wizard meminta provider → API key → model,
lalu menyimpan `~/.multacd/config.yaml`. Setelah itu:

```
> /code
> baca main.py lalu jelaskan cara kerjanya

> /research
> riset cepat: model reasoning kecil terbaik 2026

> /personal
> kirim briefing sekarang ke Telegram
```

Command penting: `/help` (semua command), `/model` (ganti model),
`/clear` (sesi baru), `Ctrl+T` (file tree), `Ctrl+R` (panel sumber riset).

Update kapan saja: `multacd update`.
