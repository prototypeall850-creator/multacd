# Research Agent (/research)

Riset internet gaya Perplexity dengan search BYOK
(Tavily, Exa, Brave, SerpAPI, DuckDuckGo gratis).

- **Quick research** (~30 detik): beberapa query → scrape → sintesis.
- **Deep research** (~2–5 menit): multi-round sampai cukup sumber.
- Scraping gagal → fallback snippet, tidak crash.
- `Ctrl+R` panel sumber (round, read/failed, export `.md`).
